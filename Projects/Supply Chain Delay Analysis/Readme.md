# Supply Chain Delivery Performance Analysis

Analysis of a global e-commerce supply chain to quantify late deliveries and find their root causes.

# Overview

Over 54% of orders in this dataset were delivered late, putting an estimated $2.1M in profit at risk. This project digs into why, using EDA and bottleneck analysis across shipping, region, and time.

# What's Inside
EDA & Business KPIs — late delivery rate, profit at risk, delay trends
Bottleneck & Root Cause Analysis — by shipping mode, region, department, and order status
Time-Based Analysis — delay patterns by month, day, and hour
Power BI Dashboard — 3-page interactive dashboard summarizing all findings

# Key Findings
First Class shipping has a 100% delay rate vs. 39.8% for Standard Class
Delay rates are consistent across regions and segments — the problem is systemic, not localized
Orders stuck in PAYMENT_REVIEW status show an 80% delay rate in the highest-delay region (Central Africa)
